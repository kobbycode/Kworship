KWORSHIP 0.3.0 — WINDOWS x64 DEVELOPMENT BUILD

1. Extract the entire ZIP into a local folder on a Windows 11 x64 computer.
2. Run Kworship.exe. The .NET runtime is included; no SDK is required.
3. Choose New song. Enter an original title and lyrics, separating slides
   with blank lines. Optional section labels use [Verse 1] or [Chorus]. Save.
4. Select that song in the library and choose Preview selected.
5. Open Congregation output. Take the preview, then toggle Black off.
   Preview navigation will not change live output. Use live arrows to advance.
6. Add songs to the service. Rename it, reorder with drag/drop or arrows,
   and Save service. Saved services can be reopened or duplicated.
7. Stage output shows the committed live slide and upcoming slide, even when
   the congregation is black or visually frozen. It never shows preview edits.
8. Use Display setup to identify and assign congregation/stage screens.
   Opening an assigned screen requires confirmation and starts black.
   Windowed output is still available; F11 toggles its fullscreen mode.
   Display changes suspend output. Reopen and confirm after reconnecting.
9. Ctrl+F focuses library search. Ctrl+S saves the song when its editor has
   focus; otherwise it saves the current service. Text editing does not
   navigate live output.

DATA AND RECOVERY
Canonical songs/services: %LOCALAPPDATA%\Kworship\library.db
Drafts and layout:       %LOCALAPPDATA%\Kworship\workspace.json
Diagnostics:             %LOCALAPPDATA%\Kworship\diagnostics.jsonl
Draft recovery is debounced by 700ms and offered for review after restart.
Recovery never activates live output. Choose Recover or Dismiss before editing.
Save/discard current edits before replacing the song or service.
Back up library creates a database-only backup at a new destination; save any
pending edits first. Existing backup files are never silently overwritten.

VALIDATION LIMITS
Domain/storage/workspace tests and a Windows WPF UI smoke check gate packaging.
Windows CI exercises the WPF controls, bindings, output windows and dark theme.
Physical display behavior and visual layout require the manual Windows checklist.
This version presents text. It does not yet implement Bible data, video/audio,
images, PowerPoint, timers or streaming.
It is not validated for a live service. No songs or Bible corpus are bundled.

See THIRD-PARTY-NOTICES.txt and licenses/ for bundled component notices.

STRUCTURED SONGS
Use Sections & details to add verses, choruses and bridges; edit each section
and add it repeatedly to the custom play order. Apply, then Save song.
Author and copyright credits appear on congregation output.

UPGRADING AN OLDER LIBRARY
The first upgrade to schema v2 makes and verifies a pre-upgrade SQLite backup
next to library.db, named library.db.before-v2-<id>.db. Keep this backup.
Older app versions cannot open the upgraded library; restoring/downgrading
requires the pre-upgrade backup. Do not delete your library to fix an error.
